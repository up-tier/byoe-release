# Uptier BYOE (Bring Your Own ETF)

Uptier BYOE is a local-first desktop application for building custom
stock baskets ("Personal ETFs") and rebalancing them across brokerage
accounts. Your portfolio recipes, positions, and credentials stay on
your device: there is no cloud storage, no remote server, and no SaaS fee.

## Download

Download the installers from the Releases page of this repository:

https://github.com/up-tier/byoe-release/releases

- Windows: `Uptier.BYOE.Setup.<version>.exe`
- macOS (Intel): `Uptier.BYOE-<version>.dmg`
- macOS (Apple Silicon): `Uptier.BYOE-<version>-arm64.dmg`
- Linux: `Uptier.BYOE-<version>.AppImage` and `uptier-byoe_<version>_amd64.deb`

Pick the latest release for the current version.

## Help

New to BYOE? Read the help file: [HELP.md](HELP.md)

It covers installing BYOE, creating your first recipe, connecting a
broker, rebalancing, orders, reconciling trades made outside BYOE,
backup and restore, and troubleshooting.

## Source code

The source code is not published in this repository. This repository
contains only this README and HELP.md, and its releases contain only
the installers listed above. The "Source code (zip)" and "Source code
(tar.gz)" archives GitHub automatically generates for each release
therefore contain only this README and HELP.md.
